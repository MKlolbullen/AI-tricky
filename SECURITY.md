# Security

AI-tricky is a single-user, locally hosted assessment workbench. It can execute powerful installed security tools when the operator enables CLI execution. Application-level input checks are not an OS network sandbox.

Please keep vulnerability reports focused on the affected version, trust boundary, reproducible local steps and expected versus observed behavior. Use synthetic lab data. Do not post credentials, customer targets or captured engagement evidence in public issues.

Use GitHub private vulnerability reporting when it is available for this repository. Otherwise, open a minimal issue requesting a private reporting route without publishing exploit details or sensitive data.

The current execution boundaries and unvalidated areas are documented in the README, `docs/CATALOG-MIGRATION.md` and `docs/VALIDATION.md`. Report a bypass as a security issue; do not describe the passing fixture matrix as proof that a real deployment is fully sandboxed.
